# 청풍 앱

사내용 웹앱 두 개입니다. 폰 홈화면에 추가하면 앱처럼 쓰이고, 인터넷 없이도 열립니다.

- `estimate/` — 현장견적 (실측 → 견적서 · 도면)
- `lotto/` — 로또 번호 도우미

## 단가표는 여기 없습니다

견적앱 코드에는 **단가가 들어있지 않습니다.** 이 저장소는 공개되므로
청풍 단가표(실행가)를 넣지 않습니다.

단가는 기기마다 한 번만 넣으면 됩니다:

1. 견적앱 열기 → **[단가]** 탭
2. **[단가표 불러오기]** → `청풍-단가표.json` 선택
3. 끝. 그 기기에 저장되어 계속 쓰입니다.

`청풍-단가표.json` 은 노트북의 `청풍앱-클로드` 폴더에 있습니다.
폰으로 옮길 때는 카카오톡 "나와의 채팅" 등으로 파일을 보내두면 편합니다.

## 데이터

현장·실측·사진은 **그 기기 안에만** 저장됩니다. 서버로 가지 않습니다.
기기를 바꾸거나 백업하려면 [현장] 탭의 백업 내보내기/불러오기를 쓰세요.
